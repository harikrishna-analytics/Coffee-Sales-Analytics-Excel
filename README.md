
# ☕ Coffee Sales Analytics – Excel Project

## 📌 Project Overview
An end-to-end Coffee Sales Analysis project using Microsoft Excel. The project explores sales performance, customer behaviour, product trends, and city-wise sales through formulas, dynamic array functions, Power Query, and an interactive dashboard.

## 📊 Dataset Overview

| Dataset | Records |
|---|---:|
| Sales | 10,388 |
| Customers | 497 |
| Products | 28 |
| Cities | 14 |

## 🎯 Project Objectives
- Analyse overall sales performance.
- Identify top-performing products.
- Understand customer purchasing patterns.
- Compare sales across cities.
- Build a dynamic, formula-driven dashboard.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Advanced Excel Formulas
- Dynamic Array Functions
- XLOOKUP, INDEX, MATCH
- SUMIF, SUMIFS, COUNTIF, COUNTIFS
- FILTER, UNIQUE, SORT, SORTBY
- LET, IF, IFERROR
- Power Query
- Data Visualization

## 📈 Project Highlights
- Data cleaning and preparation using Power Query.
- Sales analysis using Excel formulas.
- Dynamic data extraction and filtering.
- Interactive dropdown-based analysis.
- Dashboard with KPI cards and charts.
- No PivotTables or VBA used.
