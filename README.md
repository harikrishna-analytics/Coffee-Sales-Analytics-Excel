# ☕ Coffee Sales Analytics – Excel Project

## 📌 Project Overview
An Excel-based Coffee Sales Analytics project showcasing two approaches to analysing sales data and building interactive dashboards:

1. **Formula-driven dashboard** using Power Query, advanced Excel formulas, and dynamic arrays.
2. **AI-assisted dashboard automation** using AI to help generate and customise VBA code, automate PivotTable summaries, and connect interactive dashboard controls.

The project explores sales performance, customer behaviour, product trends, and city-wise sales.

## 📊 Dataset Overview

| Dataset | Records |
|---|---:|
| Sales | 10,388 |
| Customers | 497 |
| Products | 28 |
| Cities | 14 |

## 🎯 Project Objectives
- Analyse overall coffee sales performance.
- Identify top-performing products and customer segments.
- Compare sales across cities.
- Create interactive dashboards for exploring sales data.
- Reduce repetitive reporting steps through data preparation and automation.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Power Query
- Advanced Excel formulas: XLOOKUP, INDEX, MATCH, SUMIF, SUMIFS, COUNTIF, COUNTIFS
- Dynamic array functions: FILTER, UNIQUE, SORT, SORTBY
- Formula helpers: LET, IF, IFERROR
- PivotTables and PivotCharts
- VBA macros and form/button controls
- AI-assisted VBA code generation and customisation
- Excel charts, KPI cards, and slicers

## 📈 Project Work

### 1. Formula-Driven Dashboard
- Combined and transformed the sales data using Power Query.
- Used XLOOKUP, INDEX-MATCH, SUMIFS and other formulas for data retrieval and analysis.
- Applied FILTER, UNIQUE, SORT and SORTBY to create dynamic analysis outputs.
- Built KPI summaries, charts, and dropdown-driven dashboard views.

### 2. AI-Assisted VBA & PivotTable Automation
- Used AI assistance to generate and customise VBA code for Excel dashboard automation.
- Created PivotTables to summarise sales data and connected them to dashboard visuals.
- Added VBA-driven buttons and controls to run dashboard actions and simplify the user workflow.
- Built interactive PivotCharts with slicers to explore sales performance across relevant categories.

> **Note:** The formula-driven dashboard demonstrates an approach without PivotTables or VBA. The second approach separately demonstrates AI-assisted VBA and PivotTable-based automation.

## 💡 Key Learning Outcomes
- Applying advanced Excel formulas and dynamic array functions to business analysis.
- Preparing and transforming data with Power Query.
- Designing interactive dashboards with KPIs, charts, dropdowns, and slicers.
- Using AI as a coding assistant to develop and customise VBA automation.
- Understanding two different ways to build and automate Excel reporting solutions.
